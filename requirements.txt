#
#  Third-Party Runtime Requirements and Dependency Scope
#
#  This file lists the third-party distributions required by the audited
#  Python workflow implementing the analytical framework in "Do Sanctions
#  Backfire? New Evidence on the Macroeconomic Effects of Supporting Ukraine"
#  by Vicente Rios, Izaskun Barba, and Lisa Gianmoena (2026). The workflow
#  reconstructs untreated country trajectories, distinguishes the 2014
#  sanctions wave from the 2022 escalation, and quantifies coalition burden
#  separately through consumer-price and real-GDP-per-capita outcomes.
#
#  Its reproducible estimates and sensitivity diagnostics provide an
#  analytical evidence layer for compensation, emergency procurement,
#  infrastructure prioritisation, and coalition-cohesion assessments.
#  Policy allocation rules require a separately specified decision layer.
#
#  Dependency-to-Method Mapping:
#  - numpy: array operations, factor projections, the residual-maker
#    matrix, SVD-based Moore-Penrose pseudoinverses (np.linalg.pinv, svd,
#    lstsq, solve, matrix_rank, eigvalsh), condition-number checks, and
#    seed-controlled PCG64 draws via np.random.SeedSequence/default_rng for
#    the country-history bootstrap, region-block bootstrap, and size-matched
#    placebo assignments.
#  - pandas: country-year panels, raw-source ingestion, eligibility and
#    completion ledgers, DataFrame.attrs provenance metadata, and output
#    tables.
#  - scipy: scipy.stats.t for country-dispersion Student-t inference with
#    N_T - 1 degrees of freedom, and scipy.stats.linregress for the bounded
#    local-trend backcasts used in control completion and outcome repair.
#  - matplotlib: headless (Agg) figure production; matplotlib.colormaps
#    and matplotlib.axes.Axes are used by the event-study and choropleth
#    renderers.
#  - geopandas: imported unconditionally by the import cell; supplies the
#    GeoDataFrame geometry branch of the European (Figure 3) and world
#    (Figure B1) choropleths.
#
#  Runtime Dependencies Not Named in the Import Cell:
#  - pyarrow: required by pandas.DataFrame.to_parquet, which persists a
#    country-dispersion inference ledger (Task 14).
#  - Jinja2: required by pandas.DataFrame.to_latex, which renders the
#    publication tables (Task 31).
#  These are loaded lazily by pandas, so the import cell succeeds without
#  them; the corresponding pipeline stages fail when they are absent.
#
#  Standard-Library Modules (no installation required):
#  builtins, copy, dis, hashlib, importlib.util, inspect, itertools, json,
#  logging, math, os, re, sys, tempfile, dataclasses, datetime, decimal,
#  pathlib, statistics, types, typing.
